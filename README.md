# 🏪 부산광역시 편의점 상권 지도 대시보드

소상공인시장진흥공단 상가(상권)정보 데이터를 기반으로 부산 전역의 편의점(약 2,780개소)을 한눈에 탐색하고 분석할 수 있는 웹 지도 애플리케이션입니다.

> **💡 CARTO 공식 인증 및 고화질 베이스맵 적용 완료**  
> 발급받으신 CARTO 공식 API 키(`cb1_42xa_1_...`)가 적용되어 워터마크 없이 **CARTO Voyager(고화질 컬러), Positron(깔끔한 화이트), Dark Matter(다크 모드), OpenStreetMap**까지 최고 해상도로 쾌적하게 구동됩니다.

---

## 🚀 빠른 실행 방법

1. `index.html` 파일을 크롬(Chrome), 엣지(Edge), 웨일(Whale) 등 선호하는 웹 브라우저에서 **더블 클릭**하여 엽니다.
2. 브라우저의 로컬 보안(CORS) 정책으로 인해 상단에 안내 배너가 표시되는 경우:
   - 상단 우측의 **[CSV 파일 열기]** 버튼을 클릭하고, 같은 폴더의 `소상공인시장진흥공단_상가(상권)정보_부산_편의점_202606.csv` 파일을 선택합니다.
   - 또는 해당 CSV 파일을 브라우저 화면 안으로 **마우스 드래그 앤 드롭**하셔도 즉시 로드됩니다.
3. 한 번 로드된 데이터는 브라우저의 로컬 저장소(LocalStorage)에 안전하게 캐싱되어, **다음부터는 열기만 해도 자동으로 즉시 점포들이 표시**됩니다.

## 🌟 주요 기능 및 특징

### 1. 지역별 필터링 (부산 16개 구·군)
- 좌측 사이드바의 **[지역 선택]** 드롭다운에서 원하는 자치구·군을 선택하세요.
  - 지원 지역: 중구, 서구, 동구, 영도구, 부산진구, 동래구, 남구, 북구, 해운대구, 사하구, 금정구, 강서구, 연제구, 수영구, 사상구, 기장군
- 구/군을 선택하면 해당 행정구역의 중심 좌표로 **부드러운 카메라 줌인 이동(FlyTo)** 이 자동으로 이루어집니다.

### 2. 편의점 종류(브랜드)별 구분 및 마커 핀
- 상호명 텍스트 정규식 분석을 통해 각 브랜드 고유 색상 및 약칭이 새겨진 커스텀 마커 핀을 제공합니다.
  - **GS25**: 🔵 스카이블루 (#007BC3) / "GS"
  - **CU**: 🟣 퍼플 (#633991) / "CU"
  - **세븐일레븐**: 🟢 그린 (#008054) / "7E"
  - **이마트24**: 🟡 옐로우 (#E59E00) / "E24"
  - **미니스톱**: 🔵 딥블루 (#005BAC) / "MS"
  - **씨스페이스**: 🔴 레드 (#E60012) / "CS"
  - **기타/개인**: ⚪ 슬레이트 그레이 (#64748B) / "기타"
- 각 브랜드 체크박스를 켜고 꺼서 특정 브랜드만 모아보거나 비교할 수 있습니다. (전체선택/전체해제 지원)

### 3. 고성능 마커 클러스터링 (Marker Clustering)
- 2,780개의 점포를 한 번에 띄워도 브라우저가 느려지지 않도록 **Leaflet.markercluster**가 적용되었습니다.
- 지도를 축소하면 인접 점포들이 숫자 원형 뱃지로 그룹화되며, 숫자를 클릭하면 해당 구역으로 줌인되거나 마커들이 거미줄(Spiderfy)처럼 펼쳐집니다.
- 화면 우하단의 클러스터링 아이콘 버튼을 눌러 클러스터 기능을 켜고 끌 수 있습니다.

### 4. 실시간 상권 통계 차트 (Chart.js)
- 지역 또는 브랜드를 필터링할 때마다 현재 지도에 표시된 편의점들의 **브랜드별 점유율 도넛 차트**가 실시간으로 자동 갱신됩니다.

### 5. 점포 상세 팝업 및 길찾기 연동
- 지도 위의 마커를 클릭하면 다음과 같은 상세 카드 팝업이 나타납니다:
  - 점포 상호명 및 지점명
  - 브랜드 뱃지
  - 도로명 주소 및 지번 주소
  - **[주소복사]** 버튼 (클립보드 즉시 복사)
  - **[길찾기]** 버튼 (카카오맵 길찾기 웹페이지 바로 연결)

### 6. 실시간 키워드 검색
- 점포명, 지점명, 도로명(예: `서면`, `해운대`, `전포`, `광안리`)을 입력하면 실시간으로 지도 마커와 좌측 점포 리스트가 필터링됩니다.
- 좌측 결과 목록에서 특정 점포를 클릭하면 해당 위치로 지도가 날아가며 팝업이 열립니다.

### 7. 지도 스타일 변경
- 상단 헤더의 셀렉트 박스에서 **밝은 지도(기본 / Carto Voyager)**, **OpenStreetMap 표준**, **다크 모드**를 자유롭게 전환할 수 있습니다.
